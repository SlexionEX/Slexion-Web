Slexion-Web · Slexion 个人官方全站源码
✨ 高颜值自研液态玻璃拟态官网，集成前端交互、多语言、小游戏生态、用户账号系统与完整 PHP 后端能力

---
📖 项目介绍
Slexion-Web 是 Slexion 个人官方网站完整开源项目，包含自研玻璃拟态 UI、动态交互页面、多语言切换、休闲小游戏套件、用户登录注册、数据存档、头像上传、用户反馈等全套前后端功能。
全站采用原生前端 + 原生 PHP 开发，轻量、高效、无框架依赖，可直接部署在普通 PHP 服务器环境。

---
📂 项目功能模块
- 首页体系：中英文双语首页、动态导航栏、液态玻璃视觉特效
- 用户系统：注册、登录、退出、个人中心、头像上传、游戏分数存档
- 休闲小游戏：斗地主联机、2048、贪吃蛇、气泡小游戏、多人游戏房间
- 工具页面：macOS 时钟、液态玻璃特效演示、前端实验页面
- 内容页面：博客日志、软件下载、用户协议、问题反馈、浏览器介绍页
- 底层能力：全局拖拽组件、i18n 国际化、后端接口封装

---
🛠 技术栈
- 前端：HTML5 / CSS3 / Native JavaScript / 自研液态玻璃渲染引擎
- 后端：原生 PHP
- 特性：多语言国际化、动态 UI、窗口拖拽、数据持久化、用户权限控制

---
🚀 部署说明
1. 纯前端预览（GitHub Pages）
仅支持静态页面展示，PHP 后端功能无法使用（登录、存档、联机等功能失效）。
2. 完整生产部署（推荐）
部署至 PHP + MySQL 环境服务器，即可启用全站全部功能：
- 用户注册登录
- 游戏分数云端存档
- 头像上传功能
- 用户反馈提交
- 斗地主联机房间服务
